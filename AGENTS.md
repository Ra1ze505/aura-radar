# AGENTS.md

## Product

Telegram-бот **Aura Radar**: по контексту группового чата оценивает ауру автора сообщения (сильная / слабая / нейтральная), редко реагирует сам и ведёт рейтинг очков **внутри чата**.

Источник правды по продукту и нарезке работ: [`docs/tz.md`](docs/tz.md).  
Этот файл — как собирать, что не ломать, куда класть код.

Если код и ТЗ расходятся — побеждает ТЗ. Продукт меняется только правкой `docs/tz.md`.

## Stack (TZ §12)

- Python 3.12+
- aiogram 3, long polling (нет HTTP-сервера, нет открытых портов)
- SQLAlchemy 2 async; SQLite по умолчанию, Postgres если задан `DATABASE_URL`
- LLM: OpenAI-compatible `chat.completions`
- тесты: pytest, без сети и без секретов

## Layout

```
src/aura_radar/    # код бота
prompts/           # или src/aura_radar/prompts/ — системный промпт судьи
tests/
docs/tz.md
```

Пока каркаса нет — первый срез S0 из ТЗ §17 его создаёт. Не плодить второй пакет с другим именем.

## Commands (когда появится pyproject)

| Task | Command |
|------|---------|
| Install | `pip install -e ".[dev]"` (или poetry/uv — как зафиксирует S0; один способ) |
| Lint | `ruff check .` |
| Tests | `pytest -q` |
| Run | `python -m aura_radar` с `.env` |
| Docker | `docker compose up --build` |

`pytest` **не** требует `BOT_TOKEN`, Postgres, LLM.

## Invariants (не нарушать)

1. Авторадар молчит, если вердикт нейтральный, низкая confidence, мелкая дельта или кулдаун — ТЗ §8.
2. Очки и контекст не пересекают `chat_id`.
3. Дешёвые фильтры авторадара **до** вызова LLM.
4. Нет секретов в git. `.env` gitignore.
5. Пользовательские строки на русском, код на английском.
6. Не реализовывать §2.2 ТЗ (баттлы, глобальный топ, веб, i18n, …).
