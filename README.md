# aura-radar

Telegram-бот, который по контексту чата оценивает ауру автора сообщения — сильная или слабая — и реагирует на это.

## Документы

- **[ТЗ для агентов и реализации](docs/tz.md)** — продукт, скоринг, реакции vs текст, команды, стек Go, нарезка работ.
- **[AGENTS.md](AGENTS.md)** — инварианты и команды для кодовых агентов.

Репозиторий на старте без кода бота. Код появляется срезами S0–S8 из ТЗ (`go run ./src`).

## Идея

В групповом чате бот смотрит недавнюю переписку и ставит мемную «ауру» на конкретный ход: плюс очки за сильную, минус за слабую.

По умолчанию:

- реакции ставит **часто**;
- текстом врывается **редко**;
- `/aura` реплаем либо **оценивает** сообщение в контексте, либо **объясняет** уже стоящую реакцию.

Рейтинг считается **только внутри чата**.

## Что нужно, чтобы потом запустить

1. Токен у [@BotFather](https://t.me/BotFather).
2. **`/setprivacy` → Disable** — иначе бот не видит обычные сообщения и не из чего брать контекст.
3. Ключ LLM (OpenAI-совместимый API) — см. `.env.example`.
4. Добавить бота в группу.

Подробные пороги, тон и схема данных — в ТЗ, не дублируем их здесь.
