# aura-radar

Telegram-бот **Aura Radar**: по контексту группового чата оценивает ауру автора сообщения — сильная / слабая / нейтральная. Сам часто ставит реакции, редко пишет в чат, ведёт рейтинг очков **внутри чата**.

## Документы

- **[ТЗ](docs/tz.md)** — продукт, скоринг, реакции vs текст, команды, стек, нарезка работ.
- **[AGENTS.md](AGENTS.md)** — инварианты для кодовых агентов.

## Локальный запуск

Нужны Go 1.23+ и токены (не коммитить).

```bash
cp .env.example .env
# заполнить BOT_TOKEN и OPENAI_API_KEY
go run ./src
```

Или:

```bash
docker compose up --build
```

`go test ./...` проходит **без** токенов, Postgres и сети.

### Env

| Имя | Зачем |
|---|---|
| `BOT_TOKEN` | токен BotFather; также читается `AURA_RADAR_BOT_TOKEN` |
| `OPENAI_API_KEY` | ключ LLM; также читается `AURA_RADAR_OPENAI_API_KEY` |
| `OPENAI_MODEL` | например `x-ai/grok-4.6` |
| `OPENAI_BASE_URL` | по умолчанию `https://api.openai.com/v1`; для OpenRouter — `https://openrouter.ai/api/v1` |
| `DATABASE_URL` | SQLite-путь или `postgres://...` |
| `AURA_ALLOWED_CHAT_ID` | если задан — бот в группах отвечает только этому `chat_id` |
| `AURA_ALLOWED_CHAT_TITLE` | если id нет — фильтр по точному названию группы |

Пороги авторадара — в `.env.example` и ТЗ §8.3.

Голос, кружки (`video_note`) и видео со звуком: бот качает файл из Telegram и распознаёт речь через OpenAI-совместимый STT (`OPENAI_TRANSCRIBE_MODEL`). Фото и картинки-файлы: vision-описание той же моделью, что судья (`OPENAI_VISION_MODEL`, по умолчанию `OPENAI_MODEL`). Дальше — как текст. Стикеры без текста не оцениваются.

Как узнать `chat_id` закрытой группы: бот должен быть в чате, privacy mode выключен; в логе после первого апдейта будет `allowed_chat_id`, либо через `getUpdates` у Bot API. Значение в чат агенту не обязательно присылать.

### BotFather (вручную)

1. Создать бота, взять токен.
2. `/setprivacy` → **Disable** — иначе нет буфера контекста, только команды.
3. `/setjoingroups` → Enable.
4. Команды меню: `start`, `help`, `aura`, `top`, `radar`.
5. Добавить бота в группу. Админские права не обязательны. Если админ сузил набор реакций чата до эмодзи вне `🔥🗿🤡🤣🌚👀`, реакции могут не ставиться.

### Секреты для Cloud Agent

`BOT_TOKEN` и `OPENAI_API_KEY` **не писать в чат** с агентом. Их кладут в дашборд Cursor как **Runtime Secret**: [Cloud Agents → Secrets](https://cursor.com/dashboard/cloud-agents) (с телефона — браузер, не приложение). Имя модели можно написать текстом. После сохранения нужен новый агент. Подробности: [ТЗ §13.4](docs/tz.md).

Локально: `.env` из `.env.example` (файл в git не попадает).

## Команды

| Команда | Что делает |
|---|---|
| `/start` `/help` | онбординг |
| `/aura` реплаем | оценить сообщение или объяснить уже стоящую реакцию (очки не пересчитывает) |
| `/aura` без реплая | твой счёт в этом чате |
| `/aura @user` | счёт пользователя |
| `/top` | топ-10 чата |
| `/radar on\|off` | админ чата включает/выключает авторадар |

## Инварианты

- нейтраль авторадаром — молчание;
- нет реакции — нет авто-очков и нет события;
- `/aura` на сохранённое событие не пересчитывает очки;
- очки и контекст не пересекают `chat_id`.
